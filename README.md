# StarTable Tokyo

东京 2026 全部星级米其林餐厅数据库。

## 数据规模
- 三星：12 家
- 二星：26 家
- 一星：122 家
- 合计：160 家

## 当前内容
- 餐厅中文/日文/英文名
- 米其林星级、菜系、地区
- 地址、电话或公开电话状态
- 最近车站、步行时间、交通线路
- 官网/预约链接
- Lunch / Dinner course、价格与可筛选价格区间
- Tabelog 评分
- Dress Code 与儿童政策
- Lunch、Dinner、价格、着装、儿童政策独立筛选字段
- 地理顺序、星级、评分、价格、预约难度排序
- 区域快捷浏览
- 收藏与三店对比
- 餐厅详情弹窗
- 字段来源状态、最后更新时间与免责声明
- 地图视图
- 独立餐厅详情页：`restaurant.html?id=餐厅id`
- 字段级来源/更新时间提示
- 静态 CMS 管理表：`admin.html`
